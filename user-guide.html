Using the Quality Assessment Report

The report brings observation metadata, data-product checks, pipeline results, warnings, and supporting diagnostics into one page. Start with the overall assessment, review any warnings, and then use the product and pipeline sections to investigate the result.

Help and navigation

  • Select the ? button in the report banner to open this guide.
  • Select Back to Quality Assessment Report at the top of this page or the warnings page to return to the report.

Observation Summary

Use this section to confirm that you are reviewing the intended observation. It shows the project and scheduling block identifiers, observation times, observing mode, time on source, baseline range, array configuration, station count, and observing band.

  • Select the Project ID to open the related project information.
  • Select the Scheduling Block ID to open the related scheduling-block information.
  • Select Overview in the section header to review sources and scan intents, station health, telescope and hardware issues, spectral setups, weather and ionospheric conditions, and a target elevation plot.

Overall Assessment

The QA score and assessment summarise the observation-level result. The supporting text distinguishes critical failures from non-blocking issues, and the generated timestamp shows when the assessment was produced.

QA Summary and status indicators

The summary separates outcomes for data products and the pipeline. Counts are grouped by status:

PassedThe check met its acceptance criteria.
WarningA non-blocking result requires review.
FailedThe check did not meet its acceptance criteria.

Select Review to open the complete warnings page. Each warning includes its pipeline stage, affected product or scan, threshold, and measured result.

Observatory data products

Products are organised into expandable categories for calibrated visibilities, continuum images, spectral cubes, and ancillary data. Calibration-table files, the pipeline log, and the RFI flag command log are included under Ancillary data.

  • Select a category row to expand or collapse its product table.
  • Use Expand All or Collapse All in the section header to change every category at once.
  • Review each product’s file size, and its QA outcome and QA score, in the table.
  • Hover over or focus a linked product name for more detail: image and cube products show channel count, frequency range, image dimensions, and pixel size; the calibrated visibilities product shows frequency range, channel count, frequency resolution, and time resolution. Keyboard users can move focus with Tab.
  • View QA opens a detailed QA page for a product where one exists. The calibrated visibilities, the continuum image, and each spectral cube each have their own QA page. The image and cube pages show a QA score, RMS noise, photometric and astrometric QA scores, image metadata, and a preview. The calibrated visibilities QA page shows Measurement Set metadata, a spectral window breakdown, and diagnostic plots — baseline distribution, flagging statistics, phase and amplitude vs time, amplitude vs uv-distance, amplitude vs frequency, and continuum uv-coverage; the phase/amplitude-vs-time and amplitude-vs-uv-distance plots link through to a page showing that diagnostic for every source in the observation. For products without a dedicated page, View QA is a placeholder control.
  • View on the pipeline log and flag command log rows under Ancillary data opens that file directly in a new browser tab for reading, rather than a QA page.

Pipeline QA

This section shows the processing workflow in execution order. Each stage displays its status, a short result summary, and elapsed time. Warning stages are highlighted in amber to help locate the source of a QA warning. Every stage name is a link to a dedicated page with stage-specific detail.

  • Compare the stage results with the overall completion status and total runtime.
  • Select the Raw data validation stage name to open its validation checklist, covering schema, metadata, antenna and station tables, frequency and time axes, checksums, and flag table initialisation.
  • Select the RFI flagging stage name to open the RFI Summary, including the flagging strategy, percentage of samples flagged, and an RFI occupancy plot.
  • Select the Calibration stage name to open the Calibration Report, with sections for flux, delay, bandpass, gain, polarisation, and applied calibration.
  • Select the Imaging & deconvolution stage name to open the Imaging & Deconvolution page, covering UV-coverage plots and per-image diagnostics for the continuum image and each spectral cube.
  • Use the key pipeline metrics to review visibility retention, gain solution quality, image fidelity, and catalogue reliability.
  • Select View pipeline log in this section to open the full pipeline log in a new browser tab, and View flag commands below it to open the RFI flagging command log. The RFI Summary, Calibration Report, and Imaging & Deconvolution pages each include their own View pipeline log link for that stage.

Stage detail pages

The RFI Summary, Calibration Report, and Imaging & Deconvolution pages share a common layout: a persistent contents sidebar on the left links to each section, colour-coded amber or green to flag a warning or a pass. Sections with a result show their QA score alongside the heading.

  • Select View config parameters, or a section's own link, to jump to an expandable Configuration parameters section listing the settings used to produce that result. On the Imaging & Deconvolution page, each image has its own configuration parameters rather than one shared list.
  • On the Imaging & Deconvolution page, the UV coverage section at the top shows the continuum band's coverage plus a sparser, representative-channel UV plot for each spectral cube. Below that, each image — the continuum image and each spectral cube — has its own section with a thumbnail, image details, and photometric, astrometric, and sensitivity checks. Select View other imaging products below a thumbnail to see that run's residual map, clean component mask, point spread function, and model image.
  • The Raw Data Validation page does not have a pipeline log link or a configuration parameters section.

Recommended review sequence

  1. Confirm the observation identifiers and metadata.
  2. Read the overall assessment and QA score.
  3. Check the QA Summary for warnings or failures.
  4. Open Review for warning details.
  5. Inspect the affected product category and pipeline stage.
  6. Open a product's View QA page, or the relevant stage page — Raw Data Validation, RFI Summary, Calibration Report, or Imaging & Deconvolution — for stage-specific detail.
  7. Open a stage's configuration parameters to check the settings used, if the result is unexpected.
  8. Open the pipeline log, from the Pipeline QA section or a stage page, or the flag command log from the Pipeline QA section, when deeper troubleshooting is required.

This interface is a static mock-up with representative data.
